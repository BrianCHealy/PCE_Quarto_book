McNemar’s test and kappa statistics

Program in Clinical Effectiveness

Goal: This practicum will show how to complete McNemar’s test and kappa statistics in R.

McNemar’s test

Please open the McNemar_test.csv dataset from the course website and call it mcnem. This dataset provides the data described in the lecture. In particular, the dataset includes the relapse status at year 1 and year 5 for each of the 178 subjects. This dataset is in wide format because the repeated measures on the patient are listed in separate columns. In this format, each row contains all information about a patient. The wide format is required for a McNemar’s test in R.

The alternative format is the long format in which each observation has a separate row, and each patient has multiple rows. The long format will be required to use the Mantel-Haenszel approach for paired data. There is a link between McNemar’s test and the Mantel-Haenszel approach that you will learn about in future courses.

In order to see the number and proportion of subjects who had a relapse at each year, we can use the tabulate command that we have learned in previous practicums.

table(mcnem$year1)

  0   1 
133  45 
prop.table(table(mcnem$year1))

       0        1 
0.747191 0.252809 
table(mcnem$year5)

  0   1 
142  36 
prop.table(table(mcnem$year5))

        0         1 
0.7977528 0.2022472

As we can see, 45 subjects had a relapse in year 1, which corresponds to 0.253 of the subjects. A smaller proportion of subjects had a relapse in year 5. In particular, only 36 subjects had a relapse in year 5, which corresponds to 0.202. To see the discordant and concordant pairs, we can use the table command.

table(mcnem$year1, mcnem$year5)
   
      0   1
  0 123  10
  1  19  26

On this table, the presence/absence of a relapse at year 1 is the row variable, and the presence/absence of a relapse at year 5 is the column variable. Therefore, the number of subjects who had a relapse at year 5 and no relapse at year 1 is 10, and the number of subjects who had a relapse at year 1 and no relapse at year 5 is 19.

Despite the difference in the proportion, we would like to formally compare the groups. Since we observed the same subjects at the two time points, we must account for the pairing in the analysis using McNemar’s test. One approach for fitting McNemar’s test in R is to use the mcnemar.test command and output are shown here.

mcnemar.test(mcnem$year1, mcnem$year5)

    McNemar's Chi-squared test with continuity correction

data:  mcnem$year1 and mcnem$year5
McNemar's chi-squared = 2.2069, df = 1, p-value = 0.1374

Note that the output looks similar to the output from the chisq.test command that we have seen in previous practicums. As with the chisq.test command, the default is to include a continuity correction. The resulting p-value is slightly different than the p-value the lecture and Stata because of the continuity correction, but the conclusion is similar.

If we would like to match the results from the lecture and Stata, we can add correct=F to the command.

mcnemar.test(mcnem$year1,mcnem$year5,correct=F)

    McNemar's Chi-squared test

data:  mcnem$year1 and mcnem$year5
McNemar's chi-squared = 2.7931, df = 1, p-value = 0.09467

In order to calculate the exact p-value for McNemar’s test and the confidence interval for the odds ratio, we can use the mcnemar.exact command from the exact2x2 library. In R, there are many additional commands that we can use for specialized analyses that require loading additional libraries. You need to install the exact2x2 first (install.packages(exact2x2)), and then we can load this library.

library(exact2x2)
Loading required package: exactci
Loading required package: ssanv
Loading required package: testthat

Now, we can use the mcnemar.exact command in a similar way to how we used the mcnemar.test command, but we get different statistics:

mcnemar.exact(mcnem$year1,mcnem$year5)

    Exact McNemar test (with central confidence intervals)

data:  mcnem$year1 and mcnem$year5
b = 10, c = 19, p-value = 0.136
alternative hypothesis: true odds ratio is not equal to 1
95 percent confidence interval:
 0.2185962 1.1896487
sample estimates:
odds ratio 
 0.5263158

The two-sided p-value for the exact McNemar’s test of a difference between the years is shown 0.136. In addition, the estimated odds ratio (0.53) and 95% confidence interval for the odds ratio (0.22, 1.19) are provided.

Given this information, we can complete our McNemar’s test.

  1. State estimand of interest and null hypothesis: Estimand of interest: Association between year and presence of relapse; \(H_0: OR=1\)
  2. State type of data: Paired dichotomous data
  3. Determine appropriate statistical test: McNemar’s test
  4. State summary statistics if possible: \(\hat{OR}=\) 0.53
  5. Calculate 95% confidence interval and p-value (stat package): 0.22, 1.19; \(p=\) 0.136
  6. The estimated OR comparing year 5 to year 1 is 0.53 with a range of plausible values from 0.22 to 1.19. Note that an OR of 1 indicating no difference between the years is included in the confidence interval, but the interval is quite wide given our limited sample size.

Note that our 95% confidence interval for the odds ratio includes 1, which agrees with the fact that the p-value is greater than 0.05.

Relationship between McNemar’s test and one sample test of proportion

The exact McNemar’s test is equivalent to an exact one sample test of proportions. If there was no difference between the two years, we would expect that 50% of the discordant pairs would be in cell f and 50% of the discordant pairs would be in cell g. In this example, there are 10 subjects in cell f and 19 subjects in cell g for a total of 29 discordant pairs. To determine if this distribution of discordant pairs is unlikely under the null, we can use the binom.test command. In this command, we specify the number of subjects in cell f, the total number of discordant pairs, and the probability under the null (0.5):

binom.test(x=10,n=29,p=0.5)

    Exact binomial test

data:  10 and 29
number of successes = 10, number of trials = 29, p-value = 0.136
alternative hypothesis: true probability of success is not equal to 0.5
95 percent confidence interval:
 0.1793836 0.5433057
sample estimates:
probability of success 
             0.3448276

The two sided p-value from this output matches the exact p-value from McNemar’s test.

Note that we would have obtained the same p-value if we would have used the number of subjects in cell g for the command.

binom.test(x=19,n=29,p=0.5)

    Exact binomial test

data:  19 and 29
number of successes = 19, number of trials = 29, p-value = 0.136
alternative hypothesis: true probability of success is not equal to 0.5
95 percent confidence interval:
 0.4566943 0.8206164
sample estimates:
probability of success 
             0.6551724

Kappa statistic

For the second part of the practicum, please open the kappa_statistic dataset and call it kappa_data. This dataset has three variables: subject (patient identifier), rater1 (=1 for yes and =0 for no from rater 1), and rater 2 (=1 for yes and =0 for no from rater 2). In order to calculate the kappa statistic, we need to load the irr library. If you have not previously installed this library, please install the irr library using install.packages(irr).

library(irr)
Warning: package 'irr' was built under R version 4.5.3
Loading required package: lpSolve

To observe the agreement between the two raters, we can create a 2x2 table:

table(kappa_data$Rater1, kappa_data$Rater2)
   
     0  1
  0 25 10
  1  5 15

We can see in this output that 25 subjects were rated as 0 by both raters, 15 subjects were rated at 1 by both raters, 10 subjects were rated as a 0 by Rater 1 and a 1 by Rater 2, and 5 subjects were rated as a 1 by Rater 1 and a 0 by Rater 2. To calculate the kappa statistic, we can use the kappa2 command.

kappa2(data.frame(kappa_data$Rater1, kappa_data$Rater2))
 Cohen's Kappa for 2 Raters (Weights: unweighted)

 Subjects = 55 
   Raters = 2 
    Kappa = 0.441 

        z = 3.33 
  p-value = 0.000879

From the table above, we can see that the observed agreement (30/55=0.545). Using this value and the expected agreement that we calculated in the lecture, we can calculate kappa as 0.441. Finally, a p-value for the test of whether the kappa statistic is equal to 0 is provided.
