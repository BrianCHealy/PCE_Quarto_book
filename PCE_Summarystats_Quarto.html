PCE Practicum Summary Statistics for R

Data description and graphics

Goal: This practicum will go over how to calculate summary statistics and how to make simple graphics in R.

Summary statistics

In lecture, we investigated summary statistics and basic graphics. In this practicum, we will learn how to calculate summary statistics and create graphics in R.

Please read the digitalis_dataset_23.csv dataset into R by following the steps from the previous document and call the dataset dig for the remaining code below. R is case sensitive. This means that you should check if the variable names are uppercase or lowercase. In the remainder of this practicum, we will use lowercase for the variable names, but you can adjust as needed.

On Canvas, we also provide a PDF describing the Digitalis trial, which was a multicenter trial with more than 300 centers in the US and Canada. This trial aimed to estimate the efficacy and safety of Digoxin in treating patients with congestive heart failure. A teaching version of the dataset has been made available by the NHBLI, and information related to the dataset is also provided on Canvas. Please note that this dataset is only a subset of the full dataset available from NHBLI.

An important first step in many studies is to calculate summary statistics related to baseline characteristics in the sample. To calculate the summary statistics for a continuous variable, the R command summary can be used. Let’s investigate baseline age using the summary. For this command, we write the command first (summary). Then, inside the parentheses we list the dataset name before the dollar sign (dig) and the variable name within the dataset after the dollar sign (age). The following output is produced:

summary(dig$age)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  21.00   57.00   65.00   63.62   71.00   90.00

In this output, R provides the minimum (21), median (65), mean (63.6), and maximum (90).

We can also calculate additional summary statistics using separate commands. Note that for these commands, we would need to add the na.rm=T option if there were missing observations in the dataset. Here are the commands and output for calculating the mean, standard deviation, and variance.

mean(dig$age)
[1] 63.61786
sd(dig$age)
[1] 10.85402
var(dig$age)
[1] 117.8098

If we would like to calculate the median, minimum and maximum, we can use the following commands:

median(dig$age)
[1] 65
min(dig$age)
[1] 21
max(dig$age)
[1] 90

If we would like to calculate other percentiles, we can use the quantile command with the probs option to indicate the percentile we are interested in. As an example, this command will calculate the 25th and 75th percentiles.

quantile(dig$age, probs=c(0.25, 0.75))
25% 75% 
 57  71

To calculate the skewness and kurtosis, we need to install a separate library. In R, there are libraries that we can install with additional commands.

library(e1071)
skewness(dig$age)
[1] -0.5246339
kurtosis(dig$age)
[1] 0.2909112

Graphics

R has the ability to create many graphics. Although there are advanced R packages to create plots, we will focus on basic R commands at this early stage. When we make plots in RStudio, the resulting plots are shown in the lower right-hand window. We can copy and paste the plots or save the plots using the Export button above the plot.

For the histogram of age, we use the following command.

hist(dig$age, xlab="Age", main="Histogram of Age")

For this command, age is the variable name for the variable of interest. The other two options tell R the title of the x-axis and the title of the graph.

For the box plot of age, we use the following command:

boxplot(dig$age, ylab="Age", main="Box plot of Age")

Proportion

In the dataset, the variable “sex” is a dichotomous variable, so the summary statistic of interest is the proportion of males and females. As described above, sex=1 for male and sex=2 for the female. To calculate the frequency and proportion of males and females in the dataset, we can use the table and prop.table commands.

table(dig$sex)

   1    2 
4216 1227

This command provides the number of males (4216) and females (1227).

prop.table(table(dig$sex))

        1         2 
0.7745728 0.2254272

This command provides the percent of males (0.7745728) and females (0.2254272).

Group specific summary statistics

In addition to the summary statistics in the entire sample, we would often like to calculate the summary statistics in each sex separately. In R, there are a number of ways to calculate the group specific summary statistics. One approach to calculate the age in each group is to subset the data and calculate the summary statistics in each subset. To subset the data, we can choose the rows from the dataset with sex=1. Then, we can calculate the summary statistics of the age in this subset.

For this command, note that we have the same information as the original summary command from above. In particular, we are applying the summary command (summary) to the variable age from the dataset dig. The main change is that we have added [dig$sex==1,] . When we use the [], we are trying to look at a subset of the data. When we have a data frame, there are both rows and columns. The rows that we would like to focus on are identified before the comma, and the columns after the comma. By writing dig$sex==1 before the comma, we indicate that we would like the rows in which sex is equal to 1. Since we have nothing after the comma, we indicate that we would like all the columns. The result is that dig[dig$sex==1,] finds the rows in the dig dataset in which sex is equal to 1, and then the rest of the command find the summary statistics for the variable age. We can use the same concept for sex equal to 2.

summary(dig[dig$sex==1,]$age)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  22.00   57.00   65.00   63.54   71.00   90.00 
summary(dig[dig$sex==2,]$age)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  21.00   57.00   65.00   63.89   71.00   90.00

An alternative approach is to use the by command. In this command, we state the variable we are interested in (dig$age), the variable that identifies the groups (dig$sex), and the function we would like to apply to the variable (summary).

by(dig$age, dig$sex, summary)
dig$sex: 1
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  22.00   57.00   65.00   63.54   71.00   90.00 
------------------------------------------------------------ 
dig$sex: 2
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  21.00   57.00   65.00   63.89   71.00   90.00
