PCE Interaction terms for R

Interaction terms

Goal: This practicum will go over how to investigate interaction terms in linear and logistic regression using R

Multiple regression review

In class, we described how to investigate interaction terms. An interaction term implies that the effect of one predictor on the outcome is affected by another predictor in the model. Even though an interaction has a different interpretation than regression coefficients from previous models, the approach for testing for an interaction term is still based on regression coefficients.

For this practicum, we investigate the BPF dataset that we have used in previous practicums (bpf dataset). Please load this dataset into R and call the dataset bpf_data. In previous practicums, we have investigated the effect of disease activity on BPF controlling for age using the following regression equation where activity=0 for those without activity and activity=1 for those with activity:

\[ E(BPF_i)=\beta_0+\beta_1*activity_i+\beta_2*age_i \]

In this model, there is an association between both activity \((\beta_1)\) and age \((\beta_2)\). In particular, the regression equation in those without activity is:

\[ E(BPF_i)=\beta_0+\beta_2*age_i \]

The regression equation in those with activity is:

\[ E(BPF_i)=(\beta_0+\beta_1)+\beta_2*age_i \] Note that in the two models, the association between age and BPF is the same in each group \((\beta_2)\), but the intercepts in the activity group and the no activity group are different. Therefore, this model assumes parallel lines with different intercepts.

To complete this regression in R, we use the following commands.

mod1<-lm(bpf ~ activity+age, data=bpf_data)

Interaction term

It might be important to assess whether the change in BPF with age was different in the activity group and no activity group. In other words, we might want to assess if there is an interaction between age and activity in terms of the association with BPF. The regression equation in this case is given by:

\[ E(BPF_i)=\beta_0+\beta_1*activity_i+\beta_2*age_i+\beta_3*activity_i*age_i \] Based on this model, the regression equation for the no activity group is: \[ E(BPF_i)=\beta_0+\beta_2*age_i \]

The regression equation for the activity group is: \[ E(BPF_i)=(\beta_0+\beta_1)+(\beta_2+\beta_3)*age_i \] In this model, the slope and intercept were different for the two groups. Our focus for this example is to assess whether the association with age is different in the two groups. If the association with age is different, the difference in the slopes \((\beta_3)\) would be different than 0. Therefore, our focus will be this regression coefficient. As usual, we can complete the first three steps of our hypothesis test before we run the regression in R:

  1. State estimand of interest and null hypothesis: Difference in slopes (i.e. interaction between age and activity; \(\beta_3\)); \(H_0: \beta_3=0\)

  2. State type of data: Continuous outcome, dichotomous/continuous explanatory variable

  3. Determine appropriate statistical test: Multiple linear regression

There are a couple of ways to investigate an interaction using R. The first is to directly create the appropriate interaction term. I prefer this approach since I know exactly how the variable has been created. We would like a variable that is equal to age for the activity group and equal to 0 for the no activity group. This can be created using the following command:

bpf_data$inter<-bpf_data$age*bpf_data$activity

Since activity=0 for no activity group, the variable inter will equal 0 for no activity group because 0 times age is always equal to 0. Since activity=1 for the activity group, the variable inter will equal age for the activity group because 1 times age is always equal to age. Now, we can add this term to our lm command.

mod2<-lm(bpf ~ activity+age+inter, data=bpf_data)
summary(mod2)

Based on this output, we get the following regression equation:

\[ \hat{BPF}_i=\hat{\beta}_0+\hat{\beta}_1*activity_i+\hat{\beta}_2*age_i+\hat{\beta}_3*activity_i*age_i \]

where \(\hat{\beta}_0=\) 0.956, \(\hat{\beta}_1=\) -0.0197, \(\hat{\beta}_2=\) -0.0029, and \(\hat{\beta}_3=\) 9^{-4}

Based on this model, the regression equation for the no activity group is: \[ \hat{BPF}=\hat{\beta}_0+\hat{\beta}_2*age_i \]

where the intercept for the no activity group is \(\hat{\beta}_0\) 0.956, and the slope for the not activity group is \(\hat{\beta}_2=\) -0.0029.

The regression equation for the activity group is: \[ \hat{BPF}_i=(\hat{\beta}_0+\hat{\beta}_1)+(\hat{\beta}_2+\hat{\beta}_3)*age_i \] where the intercept fof the activity group is \(\hat{\beta}_0+\hat{\beta}_1=\) 0.956 \(+\) -0.0197=0.9363, and the slope in the activity group is \(\hat{\beta}_2+\hat{\beta}_3=\) -0.0029 \(+\) 9^{-4}=-0.002

Note that the difference in the slope for the activity group and the no activity group is 9^{-4}, which is the estimated \(\hat{\beta}_3\). The graph of our predicted values from this model can be created using the following commands:

bpf_data$yhat2<-predict(mod2)
bpf_data<- bpf_data[order(bpf_data$age),]
plot(bpf_data$age,bpf_data$bpf,type="n",xlab="Age (years)",ylab="BPF")
points(bpf_data$age[bpf_data$activity==1],bpf_data$bpf[bpf_data$activity==1],col="blue")
points(bpf_data$age[bpf_data$activity==0],bpf_data$bpf[bpf_data$activity==0],col="red")
lines(bpf_data$age[bpf_data$activity==1],bpf_data$yhat2[bpf_data$activity==1],col="blue")
lines(bpf_data$age[bpf_data$activity==0],bpf_data$yhat2[bpf_data$activity==0],col="red")

Based on the graph, we can see that the slopes are only a little different in the two groups. The p-value for the hypothesis test of interest is provided in the R output above (\(p=\) 0.617). Now, we can finish our analysis.

  1. State summary statistics if possible: estimated \(\hat{\beta}_3 =\) 9^{-4}

  2. Calculate confidence interval and p-value (stat package): -0.0028, 0.0046; \(p=\) 0.617

  3. The estimated difference in the slopes was 9^{-4}, and the range of plausible values for the difference in the slopes is from -0.0028 to 0.0046. There is limited evidence of a statistical interaction based on our sample.

Since there was a limited difference in the slope comparing the activity group and the no activity group, we can remove this term from the model.

In addition to this approach, R allows us to investigate interactions without generating new variables, but we must be more careful in our coding. In particular, we must tell R which variables are categorical/dichotomous and which variables are continuous. For categorical/dichotomous variables, we add factor prior to the variable name. The new regression command is given here:

mod3<-lm(bpf ~ factor(activity)+age+factor(activity):age, data=bpf_data)
summary(mod3)

This coding can be helpful if you have a categorical variable with many levels.

Interaction terms in logistic regression

Let’s return to the Logistic_regression dataset. In the logistic regression lab, we investigated a couple of univariate relationships between variables and the probability of progression in MS patients. In addition to these analyses, we might be interested in whether the effect of one variable changes in the presence of a second variable. As we learned with linear regression, we can fit interaction terms to investigate this specific hypothesis. In this case, we would like to know if the association between SNP and progression is different in disease activity group and no disease activity group. Here is the logistic regression model that we would like to fit

\[ log(Odds_i)=log(\frac{p_i}{1-p_i})=\beta_0+\beta_1*SNP_i+\beta_2*activity+\beta_3*SNP_i*activity_i \]

To investigate this hypothesis, we must create the interaction term and then fit the following model.

Logistic_regression$inter<- Logistic_regression$activity* Logistic_regression$snp
mod4<-glm(prog~ snp+ activity+ inter, data=Logistic_regression, family=binomial)
summary(mod4)

Note that there is limited evidence that the effect of SNP is different in the two groups for the RR (p=0.861, orange arrow) and the OR (p=0.861, red arrow). Please note that this is the same p-value and conclusion that we arrived at when we tested for an interaction between activity and SNP in our logistic regression model (orange arrow above). The Mantel-Haenszel test and logistic regression provide two alternative ways to think about the same hypothesis.
