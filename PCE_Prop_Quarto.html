Analysis of proportions

Program in Clinical Effectiveness

Goal: This practicum will go over how to do analysis of proportions in R.

Confidence intervals for a single proportion

For this analysis, we will use the MSQOL dataset. Please read this dataset into R.

We would like to estimate the proportion of RRMS patients with fatigue scores of at least 40. To calculate a confidence interval for this proportion, we will dichotomize fatigue using 40 as the cut-off. First, we will create a new variable called fatiglevel. We will assign fatiglevel=0 if fatigue score is less than 40 and fatiglevel=1 if fatigue score is greater than or equal 40. In R, a shorthand approach for creating this variable is to use the ifelse command. First, we must provide a name of the new variable that we are creating, which is fatiglevel (msqol$fatiglevel). Then, we will use the ifelse command, which has three parts. The first part is the condition that we are testing (msqol$fatig>=40). If the condition is true, fatiglevel will be assigned the value in the second part, which is 1 in this case. If the condition is false, fatiglevel will be assigned the value in the third part, which is 0. Now, we can calculate the number and proportion of subject with and without high fatigue.

msqol$fatiglevel<-ifelse(msqol$fatig>=40,1,0)
table(msqol$fatiglevel)

  0   1 
208  44 
prop.table(table(msqol$fatiglevel))

        0         1 
0.8253968 0.1746032

The estimated proportion of patients with fatigue score greater than or equal to 40 is \(\hat{p}=\) 0.175.

To calculate the exact binomial confidence interval for the proportion, we can use the binom.test command. For this command, we can specify the number of successes in the first part of the command and the number of observations in the second part. Note that table(msqol$fatiglevel)[2] is one approach to calculate the number of patients with fatigue score greater than or equal to 40, and sum(table(msqol$fatiglevel)) is one approach to calculate the total number of observations with a fatigue score.

binom.test(x=table(msqol$fatiglevel)[2],n=sum(table(msqol$fatiglevel)))

    Exact binomial test

data:  table(msqol$fatiglevel)[2] and sum(table(msqol$fatiglevel))
number of successes = 44, number of trials = 252, p-value < 2.2e-16
alternative hypothesis: true probability of success is not equal to 0.5
95 percent confidence interval:
 0.1298262 0.2272180
sample estimates:
probability of success 
             0.1746032

The estimated proportion is the same as above (\(\hat{p}=\) 0.175) and the 95% confidence interval is shown as well (0.13, 0.227). Note that a hypothesis test for the null hypothesis that the true probability of success is equal to 0.5 is also provided. Often, this hypothesis test is not of interest so be careful interpreting this p-value. You can change the null hypothesis to be 0.2, which was the hypothesis from class, by adding \(p=0.2\) to the end of the command. Please see ?binom.test for more information.

As described in lecture, other potential confidence intervals are sometimes used as well and these are easily implemented in R. For example, the Wilson confidence interval, which is recommended by many authors, can be calculated using the prop.test command. Note that this command is very similar to the binom.test command, but we must include the correct=F option to get the Wilson interval.

prop.test(x=table(msqol$fatiglevel)[2],n=sum(table(msqol$fatiglevel)), correct=F)

    1-sample proportions test without continuity correction

data:  table(msqol$fatiglevel)[2] out of sum(table(msqol$fatiglevel)), null probability 0.5
X-squared = 106.73, df = 1, p-value < 2.2e-16
alternative hypothesis: true p is not equal to 0.5
95 percent confidence interval:
 0.1327152 0.2262628
sample estimates:
        p 
0.1746032

Note that the estimated proportion is the same as above, but the confidence interval has changed slightly. Note that a hypothesis test for the null hypothesis that the true probability of success is equal to 0.5 is also provided as in the binom.test command, but we can change this by adding another part to the command.

Two sample test of proportions

In lecture, we investigated the effect of a single nucleotide polymorphism on the probability of disease progression in patients with multiple sclerosis. The dataset for this analysis is the 2x2table.csv dataset. In this dataset, we have the variable snp that equals 1 for patients with the SNP and 0 for patients without the SNP, and we have the variable prog that equals 1 for patients who progressed and 0 for patients who failed to progress.

Please load the 2x2table.csv dataset into R and call the dataset, snp_data.

Before we look at the data, we can complete the first three steps of our hypothesis test:

  1. State estimand of interest: \(p_{SNP-}-p_{SNP+}\)

  2. State the type of data: Dichotomous outcome, dichotomous predictor

  3. Determine appropriate statistical method: Two sample test of proportions

In this case, we would like to estimate the difference in the probability of progression patients without the SNP and those with the SNP. First, let’s look at a cross tabulation of the data. Create a table using snp as the row variable and prog as the column variable:

table(snp_data$snp, snp_data$prog)
   
      0   1
  0 103  13
  1  62  12

Of those patients without the SNP (top row), 13 progressed, and 103 failed to progress. Of those patients with the SNP (bottom row), 12 progressed, and 62 failed to progress.

Now let’s look at a table of the row proportions. When we add the option 1 to the prop.table, we get the row proportions. If we use the option 2, we get column proportions. If we do not add an option to prop.table, we get total sample proportions.

prop.table(table(snp_data$snp, snp_data$prog),1)
   
            0         1
  0 0.8879310 0.1120690
  1 0.8378378 0.1621622

Of those patients without the SNP, 0.112 progressed, and 0.888 failed to progress. Of those patients with the SNP, 0.162 progressed, and 0.838 failed to progress.

There are a number of ways to complete this analysis in R. The first is to complete a test of proportions using the prop.test command. This test provides you with the summary statistics as well as the p-value for the hypothesis test. The correct=FALSE option specifies that we are not using the continuity correction in our test. The default uses the continuity correction.

prop.test(table(snp_data$snp, snp_data$prog),correct=FALSE)

    2-sample test for equality of proportions without continuity correction

data:  table(snp_data$snp, snp_data$prog)
X-squared = 0.99215, df = 1, p-value = 0.3192
alternative hypothesis: two.sided
95 percent confidence interval:
 -0.0516337  0.1518201
sample estimates:
   prop 1    prop 2 
0.8879310 0.8378378

The output presented here provides the sample proportions in each group. R reports the proportion that failed to progress (\(prog=0\)) rather than the proportion that progressed (\(prog=1\)). The estimated difference in the proportion who failed to progress is \(\hat{q}_{SNP-}-\hat{q}_{SNP+}=\) 0.888 \(-\) 0.838= 0.05. Note that we use the notation \(\hat{q}\) for the proportion who failed to progress as opposed to \(\hat{p}\) which represented the proportion who progressed. The output also presents the Wald 95% confidence interval for the difference of the proportions (\(\hat{q}_{SNP-}-\hat{q}_{SNP+}\): -0.052, 0.152). Finally, R provides the two-sided hypothesis test p-value (\(p=\) 0.319).

If we wanted R to report the proportion who progressed in the two groups we could use this command.

prop.test(table(snp_data$snp,(1-snp_data$prog)),correct=F)  

    2-sample test for equality of proportions without continuity correction

data:  table(snp_data$snp, (1 - snp_data$prog))
X-squared = 0.99215, df = 1, p-value = 0.3192
alternative hypothesis: two.sided
95 percent confidence interval:
 -0.1518201  0.0516337
sample estimates:
   prop 1    prop 2 
0.1120690 0.1621622

Note that the p-value and the conclusion is the same as above, but the confidence interval has the opposite sign. The sign of the confidence limits has changed because the estimated difference between the proportions is now the proportion that progressed in SNP- minus proportion that progressed in SNP+ \(\hat{p}_{SNP-}-\hat{p}_{SNP+}=\) 0.05.

With this information, we can complete our analysis.

  1. State estimate: \(\hat{p}_{SNP-}-\hat{p}_{SNP+}=\) 0.05
  2. Calculate 95% confidence interval and p-value (stat package): 95% CI: -0.052, 0.152; \(p=\) 0.319
  3. Write conclusion: Based on our sample, the range of plausible values for the difference in the proportions is -0.052 to 0.152. No difference between the groups is one of the plausible values.

Chi-squared test

The more common way to test the same hypothesis is to use a chi-square test, and the chisq.test command will run the chi-square test. Again, the default uses the continuity correction, while the correct=FALSE option will turn it off:

chisq.test(table(snp_data$snp, snp_data$prog),correct=FALSE)

    Pearson's Chi-squared test

data:  table(snp_data$snp, snp_data$prog)
X-squared = 0.99215, df = 1, p-value = 0.3192

The results from above provide the p-value for the test of an association between the two measures (\(p=\) 0.319). There is no estimate of the association from this command, but we will show how to get an estimate of the association from another command.

Fisher’s exact test

We can test the same hypothesis with Fisher’s exact test. The first three steps of the hypothesis test are the same as above, but we use the fisher.test command:

fisher.test(table(snp_data$snp, snp_data$prog))

    Fisher's Exact Test for Count Data

data:  table(snp_data$snp, snp_data$prog)
p-value = 0.3803
alternative hypothesis: true odds ratio is not equal to 1
95 percent confidence interval:
 0.596721 3.896397
sample estimates:
odds ratio 
  1.529888

The results from above provide the p-value for the test of an association between the two measures (\(p=\) 0.38).

Estimates of association

In order to calculate other estimates of the association when we have a dichotomous predictor and a dichotomous outcome, we can use the extensive set of commands in the epitools library. Within this library, there are separate commands for the calculation of the risk ratio and odds ratio. Note that we used the prop.test command to calculate the risk difference and the associated 95% confidence interval. To calculate risk ratio, we install the library and use riskratio command. For this command, we list the predictor (snp) as “x” and the outcome (prog) as “y”, and we get the following results:

library(epitools)
riskratio(x=snp_data$snp,y=snp_data$prog)

From this set of results, we get both the chi-squared test p-value (0.319) and Fisher’s exact test p-value (0.38). Further, we get the estimated risk ratio (1.45) and the associated 95% confidence interval (0.7, 3). Using these results, we can perform our analysis:

  1. State estimand of interest: \(\frac{p_{SNP+}}{p_{SNP-}}\); \(H_0: \frac{p_{SNP+}}{p_{SNP-}}=1\)
  2. State type of data: Dichotomous outcome, dichotomous predictor
  3. Determine appropriate statistical test: Chi-squared test with risk ratio estimate
  4. State estimate: \(\hat{RR}=\frac{\hat{p}_{SNP+}}{\hat{p}_{SNP-}}\) = 1.45
  5. Calculate 95% confidence interval and p-value (stat package): 95% CI: 0.7, 3; \(p=\) 0.319
  6. Write conclusion: Based on our sample, the range of plausible values for the risk ratio is 0.7 to 3. No difference between the groups is one of the plausible values.

To calculate odds ratio, we can use the oddsratio command. For this command, we list the predictor as “x” and the outcome as “y”, and we get the following results:

From this set of results, we get both the chi-squared test p-value (0.319) and Fisher’s exact test p-value (0.38). Further, we get the estimated odds ratio (1.53) and the associated 95% confidence interval (0.64, 3.62). Using these results, we can perform our analysis:

  1. State estimand of interest: \(\frac{Odds_{SNP+}}{Odds_{SNP-}}\); \(H_0: OR = \frac{Odds_{SNP+}}{Odds_{SNP-}} =1\)
  2. State type of data: Dichotomous outcome, dichotomous predictor
  3. Determine appropriate statistical test: Chi-squared test with odds ratio estimate
  4. State estimate: \(\hat{OR} = \frac{\hat{Odds}_{SNP+}}{\hat{Odds}_{SNP-}}=\) 1.53
  5. Calculate 95% confidence interval and p-value (stat package): 95% CI: 0.64, 3.62; \(p=\) 0.319
  6. Write conclusion: Based on our sample, the range of plausible values for the odds ratio is 0.64 to 3.62. No difference between the groups is one of the plausible values.
