PCE Practicum MH for R

Analysis of dichotomous outcomes: Stratified analysis and the Mantel-Haenszel approach

Goal: This practicum will go over how to complete a stratified analysis and complete a Mantel-Haenszel test in R.

Crude analysis

Please load the MHanalysis.dta dataset into R. We are going to investigate the relationship between the presence or absence of a SNP and the presence or absence of disease progression as we did in the previous practicum for 2x2 tables. In this practicum, we will extend the ideas to stratify on a third variable and perform the Mantel-Haenszel approach.

As a first step in most analyses, we perform a crude analysis, which estimates the association between the predictor (SNP+ vs. SNP-) and the outcome (Prog+ vs. Prog-) without accounting for other variables. This is the same as the 2x2 table analysis from the previous practicum. There are several commands that we can use for this in R, but we will use the riskratio and oddsratio commands from the epitools library since it provides multiple summary statistics in a single command:

library(epitools)

Stratified analysis

In addition to the analysis in all subjects together, we can also look at the analysis stratified on another factor. As a first stratified analysis, we will use the variable activity as a dichotomous variable because all subjects in the dataset were classified as either having disease activity (activity=1) or not having disease activity (activity=0). To perform the stratified analysis, we can create two subsets of the original dataset, and then we can use the riskratio and oddsratio commands. In addition to the previous analysis, we could also perform a stratified analysis based on age. Since age is a continuous variable in this dataset, we will first need to categorize age by generating a new variable called agecategory. We will break age into three categories for this analysis using these categories:

  1. agecategory=1 if age<30

  2. agecategory=2 if age>=30 & age<33

  3. agecategory=3 if age>=33

The R commands for this are:

MHanalysis$agecategory<-NA
MHanalysis$agecategory[MHanalysis$age<30 & !is.na(MHanalysis$age)]<-1
MHanalysis$agecategory[MHanalysis$age>=30 & MHanalysis$age<33 &!is.na(MHanalysis$age)]<-2
MHanalysis$agecategory[MHanalysis$age>=33 & !is.na(MHanalysis$age)]<-3

Mantel-Haenszel approach

For our final analysis, we would like to (1) estimate the association between SNP and progression controlling for a third variable and (2) assess if there is a difference in the association between SNP and progression in the levels of the third variable. The first question addresses confounding by the third variable, and the second question addresses effect modification by the third variable. In R, we can address both of these using the same command from the epiR library. You will need to install this library as we have done with other libraries previously.

install.packages(“epiR”)

Within this library, we will use the epi.2by2 command. This command has a syntax similar to prop.test that we learned in the proportions practicum. This is an alternative way to get the crude analysis. Note that the risk ratio, odds ratio and chi-squared test p-value from this output match those from above.

For our final analysis, we would like to (1) estimate the association between SNP and progression controlling for age category and (2) assess if there is a difference in the association between SNP and progression score across the age categories. The first question addresses confounding by age category, and the second question addresses effect modification by age category. In R, we can address both of these using the same command by adding a dimension to the table command.

epi.2by2(dat=table((1-MHanalysis$snp),(1-MHanalysis$prog), 
MHanalysis$agecategory),method="cohort.count")

This output shows the crude RR, which is the estimated RR from the previous analysis that did not account for age category (1.45). Note that this matches the RR from the previous crude analyses. The M-H combined RR is the RR combining over the three groups (1.46). Note that there is only a small difference between the crude and adjusted RR in this case that they appear to be the same, but this does not have to be the case in general. The 95% confidence interval for each of the RRs are also provided. The 95% CI for the adjusted RR includes 1 (0.7, 3.04).

The final part of the output provides a test for homogeneity, which is asking whether the RR in the age categories are equal. The p-value is large (\(p=\) 0.47), showing that there is no evidence that there is a difference in the RR in the three groups.

Note that the crude OR (1.53), adjusted OR (1.56) and test for homogeneity of the ORs (0.54) are all presented in the output as well.
