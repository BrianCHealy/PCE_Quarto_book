PCE Oneway ANOVA for R

One-way ANOVA

Goal: This practicum will go over how to complete one-way ANOVA in R.

One-way ANOVA

Please load the diet dataset into R.

For this example, we were interested in the impact of four different diets (Diet 1, Diet 2, Diet 3, Diet 4) on the weight (in grams) of mice. In all, 40 mice (10 per group) contributed to our experiment. Our null hypothesis is that the mean in each of the groups will be the same (\(\mu_1=\mu_2=\mu_3=\mu_4\)), and our alternative hypothesis is that at least one of the groups is different. Since we have a continuous outcome with a categorical predictor, we will analyze this data using one-way ANOVA.

Since one-way ANOVA will start with an assessment of whether the four groups have the same mean, we will start with the steps for a hypothesis test:

  1. State null hypothesis in terms of association of interest

  2. State type of data

  3. Determine appropriate statistical approach

  4. State estimate of association

  5. Calculate p-value and confidence interval

  6. Decide whether to reject or not reject the null hypothesis

Before we look at the data, we can complete the first three steps of our hypothesis test:

  1. State null hypothesis in terms of association of interest: \(H_0: \mu_1=\mu_2=\mu_3=\mu_4\), \(H_A:\) at least one mean is different

  2. State type of data: Continuous outcome, categorical predictor

  3. Determine appropriate statistical approach: ANOVA

Now, we will summarize and graph the data to ensure that we do not have any outliers or data entry issues. To do this, we will use the by and boxplot commands.

The following command summarizes the variable weight in each diet group separately. To learn more about the by command, please type ?by. In this help file, you will note that the first part of the command is the data that we would like to investigate, the second part of the command defines the groups, and the third part of the command lists the function that we would like to use in each of the groups.

by(diet$weight, diet$diet, summary)

We can also create group specific box plots:

boxplot(diet$weight~diet$diet, xlab="Diet", ylab="Weight")

Since there are no obvious outliers or other issues with the data, we will proceed to complete our analysis. The first approach to do this is to use the aov and summary functions. The aov function fits a one-way ANOVA model, and we use the summary function to see the output. In a this analysis, we can use:

mod1<-aov(diet$weight~factor(diet$diet))
summary(mod1)  
                  Df Sum Sq Mean Sq F value   Pr(>F)    
factor(diet$diet)  3  208.1   69.37   7.637 0.000448 ***
Residuals         36  327.0    9.08                     
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

Note that we must specify here factor(diet$diet) so that R knows that the variable diet is a categorical variable rather than a continuous variable. If we did not specify factor, R would treat diet as a continuous variable.

This command tests the null hypothesis from above (\(H_0: \mu_1=\mu_2=\mu_3=\mu_4\)).

The p-value is 4^{-4}, which is less than 0.05. Therefore, we reject the null hypothesis and conclude that at least one of the means is different. To formally complete our hypothesis test, we complete the remaining steps.

  1. State summary statistics: \(\bar{x_1}=\) 25.4 grams, \(\bar{x_2}=\) 22.3 grams,\(\bar{x_3}=\) 19.9 grams, \(\bar{x_4}=\) 19.8 grams

  2. Calculate p-value (stat package): \(p=\) 4^{-4}

  3. Decide whether to reject or not reject the null hypothesis: Reject \(H_0\)

An alternative approach to perform a one-way ANOVA is to use the anova function combined with the lm function. The anova function extracts the ANOVA table from the linear model fitted by the lm function.

mod2<-lm(weight~factor(diet), data=diet)
anova(mod2)
Analysis of Variance Table

Response: weight
             Df Sum Sq Mean Sq F value    Pr(>F)    
factor(diet)  3  208.1  69.367  7.6367 0.0004476 ***
Residuals    36  327.0   9.083                      
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

As expected, the p-value for the main hypothesis is the same as using aov.

Kruskal-Wallis test

We could also have analyzed this dataset using the Kruskal-Wallis test. The Kruskal-Wallis test would be the more appropriate analysis if we believed that the normality assumption did not hold for our dataset. To complete the Kruskal-Wallis test in R, we use the kruskal.test command shown here:

kruskal.test(weight~factor(diet), data=diet)

    Kruskal-Wallis rank sum test

data:  weight by factor(diet)
Kruskal-Wallis chi-squared = 14.885, df = 3, p-value = 0.001918

Note that the p-value (0.0019) is not the same as the one-way ANOVA p-value, but it is similar and the inference would be the same in this case.
