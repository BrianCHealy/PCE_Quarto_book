PCE Cox for R

Cox proportional hazards regression model

Goal: In this practicum, you will learn how to fit a Cox proportional hazards model in R.

Introduction

In previous classes, you have learned how linear regression extended the t-test to allow any type of predictor and multiple predictors in the same model. For a survival outcome, the Cox proportional hazards regression extends the log-rank test to allow investigation of continuous, categorical and dichotomous predictors as well as multiple predictors in the same model. Cox proportional hazards regression is the most common regression approach for analysis of a survival outcome.

For linear regression, we used the following model:

\[ E(Y_i|X_i)=\beta_0+\beta_1*x_{1i}+\beta_2*x_{2i}+\beta_3*x_{3i} \]

In this model, we had an intercept (\(\beta_0\)) and a set of covariates with associated regression coefficients. We were able to perform analyses about the association between covariates and the outcome by focusing on \(\beta_1\), \(\beta_2\), or \(\beta_3\).

For Cox proportional hazards regression, we use the following model:

\[ \lambda_i(t)=\lambda_0(t)*e^{\beta_1*x_{1i}+\beta_2*x_{2i}+\beta_3*x_{3i}} \]

For this model, we assume that there is a baseline hazard of an event, \(\lambda_0(t)\), and the covariates multiply the hazard. Note that we do not have an intercept in this model, but the baseline hazard acts like the intercept. Similar to linear regression, we have a set of covariates with associated regression coefficients, and we are able to estimate the association between these covariates and the outcome using \(\beta_1\), \(\beta_2\), or \(\beta_3\).

###Single predictor

Please open the relapse.csv dataset. First, we need to load the survival library into R:

library(survival)

As we saw in previous practicums, we need to tell R the two variables involved in the time to event variable definition using the Surv option.

Here is a Kaplan-Meier curve for the time to event in each group:

plot(survfit(Surv(timetoevent2, event)~snp, data=relapse), 
col=c("black","red"))

In addition to the Kaplan-Meier curve to show the survival curves in the two groups, we can formally compare the survival distributions using the log-rank test. Here is the command and results for the log-rank test.

survdiff(Surv(timetoevent2, event)~snp, data=relapse)

snp=1 209      140    136.6    0.0821     0.219

Here are the steps for the hypothesis test using the log-rank test.

  1. State estimand of interest: Survival distribution in two groups \((H_0: S_0(t)= S_1(t))\)

  2. State type of data: Time to event outcome, dichotomous predictor

  3. Determine appropriate statistical test: Log rank test

  4. State summary statistics if possible: \(\chi^2=\) 0.219

  5. Calculate p-value (stat package): \(p=\) 0.64

  6. Based on our sample, there was a limited (no statistically significant) difference in the survival distribution between the two groups.

In addition to the log-rank test, we can compare the two groups to estimate the hazard ratio using a Cox proportional hazards model. For this analysis, we can set up our Cox proportional hazards model as

\[ \lambda_i(t)=\lambda_0(t)*e^{\beta_1*snp_i} \]

To demonstrate the meaning of the coefficient, we can write the hazard in each group.

No SNP: \(\lambda_{noSNP}(t)=\lambda_0(t)*e^{\beta_1*0}=\lambda_0(t)\)

SNP: \(\lambda_{SNP}(t)=\lambda_0(t)*e^{\beta_1*1}=\lambda_0(t)*e^{\beta_1}\)

The hazard in the no SNP group is equal to the baseline hazard, and the hazard in the SNP group is equal to the baseline hazard multiplied by a function of the regression coefficient (\(\beta_1\)). Since the hazard in the SNP group is equal to the hazard in the no SNP group multiplied by a factor, the two hazards are proportional.

In order to calculate the hazard ratio comparing the long to the short, we get the following result:

\[ HR=\frac{\lambda_{SNP}(t)}{\lambda_{noSNP}(t)}=\frac{\lambda_0(t)*e^{\beta_1}}{\lambda_0(t)}=e^{\beta_1} \]

If \(\beta_1\) equals 0, the hazard ratio would equal 1. Therefore, we estimate the association between SNP status and the outcome by focusing on \(\beta_1\).

We can fit a Cox proportional hazards model using the coxph command. The coxph command is very similar to the survfit and survdiff commands that we learned in the previous practicum. In particular, we specify the Surv object with the time to event and failure indicator on the left side of the “~”. On the right side of the “~”, we list all of the predictors, just as we have with the lm command in the past. In this analysis, we only have one predictor so we only include snp on the right side of the equation. The results from the Cox model are shown here.

mod1<-coxph(Surv(timetoevent2, event)~snp, data=relapse)
summary(mod1)

Note that R provides the estimated Cox proportional hazards regression model coefficient (0.066) and exp(coef) (1.07). As we described above, exp(coef) is the hazard ratio because of the relationship between the regression coefficient and the hazard ratio shown above. In addition to the hazard ratio, R also provides the 95% confidence interval for the hazard ratio (0.81, 1.41).

Given the R output, we can complete our analysis as we have done previously.

  1. State estimand of interest: \(HR\)

  2. State type of data: Time to event outcome, dichotomous predictor

  3. Determine appropriate statistical test: Cox proportional hazards model

  4. State estimate: \(HR=\) 1.07

  5. Calculate 95% CI and p-value: 0.81, 1.41; \(p=\) 0.64

  6. The estimated hazard ratio comparing SNP group to no SNP group is 1.07, and the range of plausible values is from 0.81 to 1.41. A hazard ratio of 1 is included in the confidence interval.

Since the hazard ratio is greater than 1, it implies that the hazard in the SNP group is higher than the hazard in the no SNP group even though no difference between the groups is included in the confidence interval. This result matches the relationship shown in the Kaplan-Meier curve above. Note that the inference from this analysis matches the inference from the log-rank test above.

(Technical note: R actually provides three p-values at the bottom of the Cox proportional hazards model output: Likelihood ratio test, Wald test and Score (log rank) test. These p-values are testing whether the full model is better than a model with no predictors. In this case, testing whether the full model is better than a model with no predictors is the same as testing whether the coefficient for snp is equal to 0. This is why the p-value for the coefficient of snp matches the Wald p-value from the bottom of the coxph output. When we have only one predictor, the Score (log rank) test p-value will match the results from the log-rank test if we use the Breslow method to handle ties.)

Multiple predictors

The strength of the Cox proportional hazards model is the ability to include multiple predictors of the time to event outcome in a single model. This allows us to assess the independent association between multiple predictors and the outcome.

As an example, we will continue our analysis of the association between SNP status and the time to event. Now, we would like to control for disease duration our analysis. To do this, we would like to fit a model including SNP and disease duration. For this analysis, we can set up our Cox proportional hazards model as

\[ \lambda_i(t)=\lambda_0(t)*e^{\beta_1*snp_i+\beta_2*dd_i} \] To complete our hypothesis test, we can write the first three steps before using R:

  1. State estimand of interest: Association between SNP and the time to event holding disease duration constant (\(\beta_1\) or \(HR\))

  2. State type of data: Time to event outcome, dichotomous predictor

  3. Determine appropriate statistical test: Cox proportional hazards model

To fit this model in R, we use coxph and add the predictors: snp+dd. The R command and output are provided here:

mod2<-coxph(Surv(timetoevent2, event) ~ snp+dd, data = relapse)
summary(mod2)
