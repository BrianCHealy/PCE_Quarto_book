PCE Graphics in R

Graphics in R

Goal: This practicum will go over how to create graphs for inclusion in papers or posters submitted for publication.

Plots

Please open the bpf dataset from the course website to complete this practicum. Please call the dataset bpf_data.

Before we begin, please note that R is an extremely flexible and powerful graphing tool. Nearly any graph you would like to make can be made using the plotting tools in R, but it may take a little patience to learn how to use the options. In this practicum, we will start by focusing on the options available in the plot command, but we will also introduce the ggplot2 library, which is a more flexible approach for plotting. We will start by creating a basic scatterplot that includes a single point per patient. On this graph, we also included basic axis labels. For the association between brain parenchymal fraction (BPF) and age, we show the basic command and resulting scatterplot here.

plot(x=bpf_data$age, y=bpf_data$bpf, xlab= "Age (years)", ylab="Brain parenchymal fraction")

The first part of the command shows the x variable, and the second part of the command shows the y variable. In addition, the xlab and ylab options allow us to label the x-axis and y-axis, respectively.

Note that if you right click on the graph, you can save the graph or you can copy the graph and paste it into another program. R allows you to save the graph in several formats that are commonly used by journals, including .eps and .emf. You can also create a .pdf or .ps file with the graph.

R allows flexibility in terms changing parts of a graph. In particular, if you would like to use filled in red plus signs for each of the points, you can add options shown here. The options pch changes the marker (blue arrow) and col changes the color (red arrow). Many additional options are available, and you can learn more about these by looking at the help menu for par and points using ?par and ?points.

plot(x=bpf_data$age, y=bpf_data$bpf, xlab= "Age (years)", ylab="Brain parenchymal fraction", pch=3, col="red")

###Graphs for subsets of data

This dataset consisted of both men and women, and we might be interested in plotting the data for just the men. To do this in R, we can subset the dataset as we have seen previously using the following command:

plot(x=bpf_data$age[bpf_data$activity==1], y=bpf_data$bpf[bpf_data$activity==1], xlab= "Age (years)", ylab="Brain parenchymal fraction", main="Disease activity")

Note that we were able to add a title “Disease activity” to the graph by adding the main option to the command as well.

Multiple groups on the same graph

As an alternative, you might want to create a graph with different markers for each group. To do this in R, we can use a similar command that creates a scatterplot for each group. To ensure that the plot is the correct size, it is often best to create a blank plot with the entire dataset using the same command as above including type=”n” to indicate that we would like a blank plot.

Once we have produced the blank plot, we can add the points for the two groups separately using the points command. Within each points command, we will use the pch and col options. For the disease activity group, we will use black open circles. For the no disease activity group, we will use red solid circles.

If you were interested in adding a legend to the graph, you can use the legend command. The first part of the command shows the desired location of the legend, which is the bottom left of the graph in this case. Then, we specify what we like the legend to say for each of the point types. Specifically, we use the label “Activity” for the black open circles, and we use the label “No activity” for the red closed circles.

plot(x=bpf_data$age, y=bpf_data$bpf, xlab= "Age (years)", ylab="Brain parenchymal fraction", type="n")

points(x=bpf_data$age[bpf_data$activity==1], y=bpf_data$bpf[bpf_data$activity==1])
points(x=bpf_data$age[bpf_data$activity==0], y=bpf_data$bpf[bpf_data$activity==0], col="red", pch=19)

legend("bottomleft", c("Activity", "No activity"), pch=c(1,19), col=c("black","red"))

Adding a best fit line

Another common thing to add to a scatterplot is a best fit line. A best fit line is usually calculated using linear regression, and R allows you to easily add a best fit line from linear regression. First, we must calculate the best fit line using linear regression with the lm and predict commands.

lm.res<-lm(bpf~age, data=bpf_data)
bpf_data$predbpf<-predict(lm.res)

If you look at the bpf_data dataset, you can see that the predicted BPF based on the linear model has been added for each patient. We can add the best fit line to the original graph by first plotting the original data using the command from above. To add the best fit line, we use the lines command. The x-variable is still age, but the y-variable for the best fit line is the predicted value, predbpf.

plot(x=bpf_data$age, y=bpf_data$bpf, xlab= "Age (years)", ylab="Brain parenchymal fraction")

lines(x=bpf_data$age, y=bpf_data$predbpf)

Continuous outcome and categorical predictor

Another common graph is to plot the values of a continuous outcome with a categorical predictor. In our present dataset, we may want to plot BPF and activity on a scatterplot to look at the individual data points. In this case, activity is a categorical variable and BPF is a continuous variable. The following plot command has the same format as above, but since activity is a factor variable, R will produce group specific box plots.

plot(x=factor(bpf_data$activity), y=bpf_data$bpf, xlab= "Disease activity", ylab="Brain parenchymal fraction")

To create a plot with the individual points, we can use the numeric variable “activity”. When we use the plot command, we can show the individual points, but we would like to adjust the x-axis to show which group is the disease activity group and the no disease activity group. First, we must remove the default x-axis using the xaxt part of the command. Then, we can add our own x-axis using the axis command. For this command, we must specify the axis we want to draw, and the value “1” means the bottom axis (blue arrow). The at command says where we would like to place the labels. The labels command states the labels that will be placed at each of the at values. Since “activity” takes on values 0 and 1, we use these in the at command (red arrow) and we provide the appropriate labels in the labels command (green arrow).

plot(x=bpf_data$activity, y=bpf_data$bpf, xlab= "Disease activity", ylab="Brain parenchymal fraction",xaxt="n")
axis(1,at=c(0,1),labels=c("No activity","Activity"))

As you can see from these brief examples, there are many options available in plotting graphs in R so please explore to learn more.

Let’s start by making a scatterplot using ggplot. We can to create a blank plot for a specific dataset using the ggplot command. The way to put a plot in the blank plot is to add layers to the graph. To add a scatterplot, we use the geom_point command, which adds points to the plot:

ggplot(data=bpf_data) +
geom_point(mapping=aes(x=age,y=bpf))

We can add labels for the x-axis and y-axis using the following labs command added to the previous command:

ggplot(data=bpf_data) +
geom_point(mapping=aes(x=age,y=bpf))+
labs(x= "Age (years)", y="Brain parenchymal fraction")

We can make the plot showing the two groups in different colors using this ggplot command, which adds the color=factor(activity) option to the geom_points command. This makes the points separately for each value of activity and provides a legend showing how to identify the colors. Other options for this can be used to change the fill, size, and shape using similar syntax.

ggplot(data=bpf_data) +
geom_point(mapping=aes(x=age, y=bpf, color=factor(activity)))+
labs(x= "Age (years)", y="Brain parenchymal fraction")

To plot only those with disease activity, we can use this ggplot command:

ggplot(data=bpf_data[bpf_data$activity== 1,]) +
geom_point(mapping=aes(x=age, y=bpf))+
labs(x= "Age (years)", y="Brain parenchymal fraction")

In the plot commands above, we could add the best fit line to the plot by calculating the predicted value and adding the line. In ggplot, we can add a second plot layer for the best fit line using the geom_smooth command:

ggplot(data=bpf_data) +
geom_point(mapping=aes(x=age, y=bpf))+
geom_smooth(method=lm, se=F, mapping=aes(x=age, y=bpf))+
labs(x= "Age (years)", y="Brain parenchymal fraction")
`geom_smooth()` using formula = 'y ~ x'

The se=F option removes the confidence standard error for the best fit line.

We can also add the best fit line using the predicted values from above by adding a different layer:

ggplot(data=bpf_data) +
geom_point(mapping=aes(x=age, y=bpf))+
geom_line(mapping=aes(x=age, y=predbpf))+
labs(x= "Age (years)", y="Brain parenchymal fraction")

The geom_smooth command without the method=lm option will provide a loess smoothed fit, which does not assume a linear relationship between the predictor and the outcome.

ggplot(data=bpf_data) +
geom_point(mapping=aes(x=age, y=bpf))+
geom_smooth(mapping=aes(x=age, y=bpf))+
labs(x= "Age (years)", y="Brain parenchymal fraction")
`geom_smooth()` using method = 'loess' and formula = 'y ~ x'

Finally, we can make the plot showing the BPF in the disease activity group and no disease activity group using these commands:

ggplot(data=bpf_data) +
geom_point(mapping=aes(y=bpf, x=factor(activity)))

There are many other options that ggplot allows so please try different options out to see learn more about this command.
